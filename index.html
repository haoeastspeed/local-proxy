Features

为高效网络调试而生

从采集到应用形成完整闭环，内置智能算法与多重安全防护，兼顾轻量与专业。

智能自动采集

内置稳定来源并自动发现更多站点，异步边扫描边筛选，达标即停；本地缓存优质结果，下次启动更快。

并发验证测速

高并发测试 TCP / HTTP / HTTPS / SOCKS 可用性与延迟，判定透明、匿名、高匿等级别并做安全风险检测。

一键应用

筛选结果一键设置为系统代理，支持全局、智能分流（PAC）、指定三种模式，退出时自动还原，不留残留。

TUN 全流量接管

内嵌 Wintun 虚拟网卡，配合本地 DNS、fake-ip 与 GeoIP 分流，接管全部 TCP 流量，覆盖不读系统代理的程序。

安全与防泄漏

Kill Switch 在节点失效时阻断连接而非回退直连，TUN 开启时自动加防火墙规则阻断 IPv6，防止真实地址泄漏。

托盘常驻与自动更新

关闭或最小化即驻留系统托盘，右键快速切换；可注册系统服务，并通过 GitHub Releases 一键自动更新。

Quick Start

三步即可使用

无需复杂配置，开箱即用。

开始扫描

打开软件进入「节点」页，点击「开始扫描」。可自行设置达标数量与可接受延迟，软件会边扫描边筛选。

选择模式并应用

在「智能分流 / 全局 / 指定」中选择需要的模式，点击「一键应用」；需要全流量接管可开启 TUN 模式。

驻留与退出

关闭窗口会驻留托盘，右键图标可快速切换节点或模式；点击退出会自动关闭并还原系统代理设置。

Modes

灵活的代理模式

按场景选择最合适的接管方式，并兼容主流订阅与协议。

全

全局代理

系统全部流量走选中的代理节点，简单直接；也可开启 TUN 实现网卡级全流量接管。

智

智能分流

基于 GeoIP 与规则自动判断：国内地址直连、需要代理的目标走节点，兼顾速度与可用性（默认模式）。

指

指定代理

手动填入代理地址，或在节点列表中选用任意节点，支持固定使用与手动热切换。

兼

广泛兼容

支持 Clash、sing-box、Base64、裸 URI 订阅导入，兼容 HTTP(S)、SOCKS4/5、Shadowsocks、VMess / VLESS、TUIC 等。
