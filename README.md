# 本地代理 · Local Proxy

一款轻量的本地代理一体化管理工具：自动采集公开网络分享的代理地址，并发验证、测速与匿名度 / 安全检测，筛选出可用节点后一键设置为系统代理。纯 Rust 构建，单文件、体积小、无外部运行时依赖。

> 中性的通用代理管理 / 网络调试工具，不内置任何付费或特定服务商节点。

## 特性
- 自动采集：内置稳定来源 + 自动发现，边扫描边筛选，达标即停
- 并发验证：TCP / HTTP / HTTPS / SOCKS 可用性、延迟、匿名度（透明 / 匿名 / 高匿）、安全风险检测
- 一键应用：全局代理 / 智能分流（PAC）/ 指定代理
- TUN 全流量接管、本地 DNS 与 fake-ip、Kill Switch、IPv6 泄漏防护、GeoIP 国内分流
- 实时流量统计；订阅兼容导入（Clash / sing-box / Base64 / 裸 URI；SS / VMess / VLESS / TUIC 等）
- 托盘常驻、关闭驻留、可注册系统服务；软件内自动更新

## 下载
前往 [Releases](https://github.com/haoeastspeed/local-proxy/releases) 下载最新「本地代理.exe」，双击运行，无需安装、无外部依赖。

## 使用
1. 打开后在「节点」页点击「开始扫描」，等待筛选出可用节点；
2. 选择模式（智能分流 / 全局 / 指定），点击「一键应用」；
3. 关闭窗口会驻留托盘，右键托盘可快速切换 / 退出；退出会自动还原系统代理。

## 安全与合规
- 免费公开代理可能被监听或篡改，请勿用于登录、支付等敏感操作，风险自负；
- 本工具不提供规避网络管制的教程，仅用于合法的网络调试与管理。
